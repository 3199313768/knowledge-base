# Knowledge Base 核心功能设计

## 范围

本轮实现登录、文件上传、文件列表、关键词搜索、文件预览，以及统一错误和加载/空状态体验。

## 用户流程

登录后进入知识库主页：

`登录 -> 文件列表 -> 上传文件 -> 等待处理 -> 搜索文件 -> 查看预览`

## 功能要求

- 登录：邮箱密码登录、当前设备退出、登录态恢复；失败时保留登录表单并支持重试。
- 上传：支持 PDF、DOCX；展示上传中、成功、失败；禁用重复提交；失败后保留当前页面。
- 文件列表：展示文件名、大小、更新时间、处理状态；支持刷新和状态筛选；空列表提供下一步操作。
- 搜索：关键词搜索文件，展示匹配结果和来源片段；覆盖搜索中、无结果和失败状态；保留搜索历史。
- 预览：查看 PDF/DOCX 文件详情、解析状态和失败原因；处理失败支持重新处理。
- 错误：只展示中文安全文案，不暴露 SQL、Token、堆栈或底层异常；网络错误支持重试，权限错误给出明确说明。
- 状态：所有远程数据视图覆盖 loading、empty、error、success，以及提交中的 disabled 状态。

## 技术边界

- 页面入口只负责组合组件。
- 认证、文件、搜索、预览分别通过 service 与 hook 访问 Supabase。
- 展示组件只接收 ViewModel，不直接接收 Supabase row。
- 复用现有基础组件和样式约定，不新增不必要依赖。
- 先补测试，再实现行为；完成后执行 TypeScript、单元测试和构建验证。

## 不包含

注册和邀请成员、角色权限管理、多格式 OCR、文件版本管理、统计报表、iOS Share Extension 新功能。

## 验收标准

1. 未登录时稳定显示登录页。
2. 登录接口失败时仍保留登录表单，并可点击“重试”。
3. 上传失败不会清空文件列表或离开当前页面。
4. 文件列表、搜索、预览均覆盖 loading、empty、error、success 状态。
5. 用户可见错误均为中文安全文案。
6. 相关测试、类型检查和构建通过。
